## 📌 Projeto em destaque

### [api-tests-playwright](https://github.com/JorgeDouettes/api-tests-playwright)

[![Testes de API](https://github.com/JorgeDouettes/api-tests-playwright/actions/workflows/tests.yml/badge.svg)](https://github.com/JorgeDouettes/api-tests-playwright/actions/workflows/tests.yml)

Suíte de testes de API para a ReqRes com Playwright + TypeScript:

- 16 cenários positivos e negativos cobrindo CRUD de usuários, paginação, registro e login
- Contratos de resposta validados com **Zod** (schemas estritos, tipos inferidos)
- Fixture customizada e data builders para manter os testes curtos e legíveis
- CI no **GitHub Actions** com typecheck, formatação e testes a cada push
- Achados de QA documentados, como a API aceitar `POST` sem campos obrigatórios e não diferenciar `PUT` de `PATCH`
